# Pocket Goblin 🟩

A vibe-coded math game to help my daughter learn her times tables. Rest of the readme is generated by Claude!

A silly, slightly gross virtual pet. You solve times-table problems to earn coins, then spend them on snacks, fancy outfits and vacations for your goblin. It burps, farts, faints when you get a problem wrong, and cheers when you're on a roll.

Everything is made of blocks (voxels), so you can build new hats, shirts, snacks and den decorations in the **Workshop**, a Minecraft-style block editor.

## Running it

It's a plain web page with no build step. Browsers won't run it from a double-clicked file, so start a tiny local server from this folder:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

### Putting it online (free)

On GitHub, go to **Settings → Pages**, set **Source** to "Deploy from a branch", and pick the branch and `/ (root)`. The game will be live at `https://<user>.github.io/pocket_goblin/`.

### Phones and tablets

It works on phones and tablets turned sideways (holding a phone upright shows a "turn your phone sideways" screen). The math games get a big on-screen number pad, and the layout shrinks to fit small screens. On a computer, nothing changes. **Grown-ups → On-screen number pad** can force the pad on (for a touchscreen laptop) or off. The Workshop only works on a computer with a mouse, and says so when opened on a phone or tablet.

Progress is saved in the browser on that computer. **Grown-ups → Download backup** saves a copy you can load somewhere else.

### Playing on more than one device

Optional: a tiny free Cloudflare Worker keeps the same goblin on several devices (see [`sync-worker/README.md`](sync-worker/README.md) to set it up). Once it's running, **Grown-ups → Sync between devices → Turn on sync** gives a goblin code like `SWAMP-TOAD-BURP-SLIME-4821` and a link. Open the link on another device, or tap **I already have a goblin** when it first starts, and the same goblin shows up there. The game still saves in the browser first, so it works offline. If two devices both played while one was offline, it asks which goblin to keep.

### Seeing what's popular

The sync Worker also keeps anonymous play counts: how many goblins have been made, which math games get played, and which activities (Shop, Vacation, Decorate...) get used. No names or answers are sent, and **Grown-ups → Share play counts** turns it off. See [Play counts](sync-worker/README.md#play-counts-whats-popular) for how to view them.

## What's in the game

| | |
|---|---|
| 🧮 **Math Games** | Six games. Type answers on the keyboard (or the on-screen number pad on phones and tablets). In all of them, a wrong answer means typing the right one to keep going. |
| ↳ **Math Dash** | 60 seconds of ×/÷ facts (up to 8×8 at first, growing to 15×15). Faster answers earn more coins, and every 5 in a row earns a combo bonus. |
| ↳ **Fart Rocket** | Fart fuel drains all the time. Right answers refuel it, and faster answers add more. Fly past clouds, birds and airplanes to the Moon and beyond. The score is the best height. |
| ↳ **Swamp Sprint** | Race 500 m against three rival goblins. Every right answer is a speed boost, and faster answers boost more. A wrong answer makes you stumble, and two in a row makes you trip on a banana peel. Rivals ease off a little when far ahead, so races stay close. |
| ↳ **Squid Smackdown** | Box Big Inky, a giant squid. Every right answer is a punch (fast answers hit harder). When he winds up a tentacle, answer before the bar runs out to dodge and counterpunch for double damage. A wrong answer gets you slapped. Knock him down 3 times to win; he gets angrier and faster each time he gets up. |
| ↳ **Goblin Café** | Ring up 10 customers per shift. Orders get harder: single items (times tables), then two-item orders, splitting the bill (division) and making change. Faster service earns bigger tips, and her Workshop snacks show up on the menu. |
| ↳ **Goblin's Homework** | The goblin did its homework "all by itself", and some answers are wrong. Check each of the 6 lines: ✓ if it's right, ✗ if it's wrong, then write the right answer (corrections show up in red pen). There's no timer. A page with no slips earns a gold star. Only answers she works out herself count toward fact levels, plus any time she gets fooled; tapping ✓ on a right answer doesn't move a fact's level. |
| 🍔 **Feed** | Toss snacks into the goblin's mouth. Some snacks cause burps. Most cause farts. |
| 🛒 **Shop** | Snacks, about 26 wearables across 7 slots (hats, face stuff, bling, shirts, back stuff, hand stuff and shoes) and 8 decor items. Click any item to try it on (or see it in the den) before buying. |
| 👕 **Wardrobe** | Put on and take off owned items and anything built in the Workshop. The **Poses** tab has 13 poses: flex, superhero, ballerina, robot, headstand, chicken dance and more. |
| 🪴 **Decorate** | Put decor out in the den (5 spots, including a wall shelf) or put it away. Decor includes a pet squid, a fart jar, a dead plant (everyone starts with one), a pet rock and a golden toilet. Some of it moves on its own, and clicking it in the den makes it do something. |
| 🛁 **Bath** | The goblin HATES this. |
| ✈️ **Vacation** | Send the goblin away for 5–20 real minutes. A "Current status" line updates while it's gone, and it comes back with a postcard. |
| 🔨 **Workshop** | Build or remix items block by block. Hats, clothes and decor have to be bought in the Shop before they can be remixed (they show a 🔒 until then). Snacks and her own creations can always be remixed. |
| Grown-ups | Press and hold the button. Shows a heatmap of which facts are fast or shaky, recent rounds, settings (including the goblin's color and the game's look) and save backups. |

Hunger, thirst, clean and fun slowly drop over real time, tuned so about 10–15 minutes a day keeps the goblin happy. The goblin never dies. It just gets dramatic.

### Classic 90s look

**Grown-ups → Game look → Classic 90s** redraws the game like an early-90s PC game: a flat, straight-on camera, 32 colors (the 16 classic EGA colors plus 16 picked for the goblin's world) with a little checkerboard dithering, thick black outlines and choppier, sprite-like animation. Everything still works the same, including items built in the Workshop. The Workshop itself stays 3D so it can still be spun around. The look is in `src/retro.js`.

### How the math practice works

Each *fact family* (like 7×8, which also covers 8×7, 56÷7 and 56÷8) has a level from 0 to 5:

- **Right and faster than the target time** (3 seconds by default; change it in Grown-ups): the level goes up.
- **Right but slow**: the level stays the same. There's no punishment for being slow.
- **Wrong**: the level drops 2.

Low-level and slow facts come up much more often; mastered ones still appear occasionally.

**Numbers grow with her.** Problems start with facts up to 8×8. When 70% of the facts in play are *solid* (level 3+) **and** 70% of the newest times table is solid, the next table unlocks with a celebration: 9s, then 10s, and so on up to 15×15. The Math Games menu shows progress toward the next unlock. In **Grown-ups → Biggest number in problems** you can leave this on Auto or pin it anywhere from 5 to 15. **Game pace** controls how much time Fart Rocket's fuel, Big Inky's tentacles and the Swamp Sprint rivals give her. On Auto (the default) each game starts at the original speed and quietly slows down a step (down to 70%) after a round where she clearly struggled (rocket out of gas in under 40 s, no knockdowns on Big Inky, last in the race), then creeps back up as she does well. It can also be pinned for every game to Relaxed (70% speed), Moderate (the original speed) or Aggressive (120%). Problems are mixed between `a × b`, `c ÷ a` and `a × ? = c`. The engine is in `src/math.js`.

## Workshop controls

- **Click or drag on blocks** to use the current tool. A drag stays on the flat layer where it started, so dragging across the top of a hat lays down a flat layer instead of stacking blocks toward you.
- **Right-click or right-drag** erases.
- **Drag on empty space** (or **Shift+drag** anywhere, or middle-drag) spins the view. **Scroll** zooms.
- **Brush size** 1×1, 3×3 or 5×5: use the buttons or `[` and `]`.
- **Tools**: `B` build, `E` erase, `P` paint, `F` fill color (recolors a whole connected patch), `C` copy a color.
- `M` mirror (both sides match), `Z`/`Y` undo/redo (one step per stroke), `1`–`0` quick colors.
- The see-through goblin shows where the item will sit. Blocks can't go inside the goblin.
- **Try it on!** saves the item and puts it on the goblin. Homemade snacks can be fed straight to it.

### Making a kid-designed item part of the game

Items made in the Workshop live only in that browser. To make one permanent, so it ships with the game and appears in the Shop for everyone:

1. In the Workshop, open the item and click **Export**. A `.json` file downloads.
2. Copy it into the `items/` folder. You can add `"price": 40`, `"desc": "..."` and `"by": "Her Name"` to the file.
3. Add the filename to `items/index.json`.

`items/party-hat.json` is an example.

## Project layout

```
index.html, style.css     page + pixel-style UI
vendor/three.module.min.js   three.js r170 (3D engine, MIT)
fonts/                    Press Start 2P + Pixelify Sans (OFL)
items/                    extra items exported from the Workshop
sync-worker/              optional Cloudflare Worker that syncs saves between devices and keeps play counts
src/
  main.js                 startup, game loop, first-time setup
  voxel.js                block models + mesh builder (with Minecraft-style shading)
  goblinModel.js          the goblin's body and the item slots
  goblin.js               animations (hop, faint, fart, dance...) and emotes
  face.js                 pixel-art face expressions
  items.js                built-in items, snacks and decor (built in code from blocks)
  lines.js                everything the goblin says + postcards  ← add jokes here!
  math.js                 times-table practice engine
  quiz.js                 the shared "type the answer" card used by all math games
  state.js                save data + stat decay
  sync.js                 optional device sync (talks to sync-worker/)
  track.js                anonymous play counts (also sent to sync-worker/)
  audio.js                all sound effects, generated in code (farts included)
  fx.js                   particles: fart clouds, hearts, confetti, bubbles
  retro.js                the "Classic 90s" look: flat camera, EGA colors, outlines
  world.js                3D scene, the goblin's den + decor spots, pixelated renderer
  screens/                home, shop, wardrobe, games (picker), gauntlet (Math Dash), rocket (Fart Rocket),
                          cafe (Goblin Café), race (Swamp Sprint), squid (Squid Smackdown),
                          workshop, vacation, parent
```

Open the browser console and type `pocketGoblin` to poke at the game while it's running.
